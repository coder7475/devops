# Terraform with AWS

Learning terraform with AWS

## Prerequisite

- AWS free account or subscription
- AWS Fundamentals
- OSI model and protocols - SSH, HTTP, HTTPS, TCP,UDP, SMTP, etc
- Visual Studio Code or preferred IDE installed
- Git installed and working knowledge of Git and Github
- Linux or Mac or WSL(Windows Subsystem for Linux)
- Linux and Shell scripting
- Basic understanding of YAML and JSON
- [Deployment Strategies](https://www.youtube.com/watch?v=uj0qDN1EWus)
- [AWS Fundamentals](https://www.youtube.com/watch?v=yUhzvVrwkV8)
- [IP Addressing](https://www.youtube.com/watch?v=G1azmL5-eQI)
